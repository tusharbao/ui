## UI/UX Practical: Design User Persona for the Users of Selected Product/System

### 30 Most Expected Oral/Viva Questions with Answers

Q1. What is a User Persona?

English: A user persona is a fictional character that represents the target users of a product.

Marathi + English: User Persona म्हणजे target users चं एक imaginary character असतं, जे त्यांच्या needs आणि behaviour दाखवतं.

Q2. Why do we create a User Persona?

English: We create user personas to understand users and design products according to their needs.

Marathi + English: Users च्या needs समजून घेण्यासाठी आणि त्यानुसार product design करण्यासाठी User Persona तयार करतो.

Q3. What are the main elements of a User Persona?

English: Name, age, gender, occupation, goals, needs, frustrations, and behaviour.

Marathi + English: User Persona मध्ये name, age, occupation, goals, needs, problems आणि behaviour असतात.

Q4. What is the target audience?

English: Target audience is the group of people for whom a product is designed.

Marathi + English: ज्या लोकांसाठी product तयार केलं जातं, त्या group ला Target Audience म्हणतात.

Q5. What is user research?

English: User research is the process of understanding users, their needs, and their problems.

Marathi + English: Users च्या needs आणि problems समजून घेण्याच्या process ला User Research म्हणतात.

Q6. What is the difference between User Persona and real user?

English: A real user is an actual person, while a persona is a fictional representation based on user research.

Marathi + English: Real User म्हणजे actual व्यक्ती, तर Persona हे research वर based असलेलं imaginary character असतं.

Q7. What is a user goal?

English: A user goal is something that a user wants to achieve using a product.

Marathi + English: User ला product वापरून जे achieve करायचं असतं, त्याला User Goal म्हणतात.

Q8. What are user needs?

English: User needs are the features or support users expect from a product.

Marathi + English: Users ला product मध्ये ज्या गोष्टींची गरज असते, त्यांना User Needs म्हणतात.

Q9. What are user frustrations?

English: User frustrations are the problems or difficulties users face while using a product.

Marathi + English: Product वापरताना users ना येणाऱ्या अडचणींना User Frustrations म्हणतात.

Q10. What is empathy in UI/UX design?

English: Empathy means understanding the feelings, needs, and problems of users.

Marathi + English: Users च्या feelings, needs आणि problems समजून घेण्याला Empathy म्हणतात.

Q11. What is demographic information?

English: It includes age, gender, education, income, and occupation of users.

Marathi + English: Age, gender, education, income आणि occupation ही Demographic Information आहे.

Q12. What is behavioural information?

English: It describes how users behave and interact with a product.

Marathi + English: Users product कसा वापरतात आणि कसा interact करतात, हे Behavioural Information मध्ये येतं.

Q13. What is a pain point?

English: A pain point is a specific problem that a user faces.

Marathi + English: User ला येणाऱ्या specific problem ला Pain Point म्हणतात.

Q14. What is a scenario in User Persona?

English: A scenario describes a situation in which a user uses a product to achieve a goal.

Marathi + English: User एखादं goal achieve करण्यासाठी product कधी आणि कसा वापरतो, याचं description म्हणजे Scenario.

Q15. What is a user story?

English: A user story describes a feature from the user's point of view.

Marathi + English: User च्या point of view मधून एखादी feature कशी उपयोगी आहे हे सांगणं म्हणजे User Story.

Q16. Which methods are used to collect user information?

English: Interviews, surveys, questionnaires, observation, and usability testing.

Marathi + English: User information collect करण्यासाठी interviews, surveys, questionnaires आणि observation वापरतो.

Q17. What is a user interview?

English: A user interview is a conversation with users to understand their needs and experiences.

Marathi + English: Users च्या needs आणि experiences समजून घेण्यासाठी त्यांच्याशी केलेली discussion म्हणजे User Interview.

Q18. What is a questionnaire?

English: A questionnaire is a set of questions used to collect information from users.

Marathi + English: Users कडून information collect करण्यासाठी तयार केलेल्या questions च्या list ला Questionnaire म्हणतात.

Q19. What is usability testing?

English: Usability testing checks how easily users can use a product.

Marathi + English: Users product किती easily वापरू शकतात हे check करण्याला Usability Testing म्हणतात.

Q20. What is a primary persona?

English: A primary persona represents the most important target user of a product.

Marathi + English: Product चा सर्वात important target user represent करणाऱ्या Persona ला Primary Persona म्हणतात.

Q21. What is a secondary persona?

English: A secondary persona represents another important user group with different needs.

Marathi + English: Primary Persona व्यतिरिक्त वेगळ्या needs असलेल्या user group ला Secondary Persona म्हणतात.

Q22. Can one product have multiple User Personas?

English: Yes, one product can have multiple personas because different users have different needs.

Marathi + English: हो, एका product चे वेगवेगळे users असल्यामुळे multiple User Personas असू शकतात.

Q23. What is a fictional name in User Persona?

English: It is an imaginary name given to represent a target user.

Marathi + English: Target user ला represent करण्यासाठी दिलेलं imaginary नाव म्हणजे Fictional Name.

Q24. Why do we add a photo to a User Persona?

English: A photo makes the persona more realistic and easier to understand.

Marathi + English: Photo मुळे Persona real वाटतो आणि समजायला सोपा होतो.

Q25. What is a User Persona template?

English: It is a predefined format used to organize user information.

Marathi + English: User ची information व्यवस्थित arrange करण्यासाठी वापरल्या जाणाऱ्या format ला User Persona Template म्हणतात.

Q26. What is the role of User Persona in UI design?

English: It helps designers create user-friendly interfaces based on user needs.

Marathi + English: User च्या needs नुसार easy आणि user-friendly interface design करण्यासाठी Persona मदत करतो.

Q27. What is the role of User Persona in UX design?

English: It helps improve the overall user experience by understanding user behaviour.

Marathi + English: User behaviour समजून घेऊन overall user experience improve करण्यासाठी Persona मदत करतो.

Q28. What happens if we design without understanding users?

English: The product may become difficult to use and may not satisfy user needs.

Marathi + English: Users ना समजून न घेता design केल्यास product वापरायला difficult होऊ शकतं आणि त्यांच्या needs पूर्ण होणार नाहीत.

Q29. What is the difference between User Persona and Empathy Map?

English: A User Persona describes a target user, while an Empathy Map describes what the user thinks, feels, says, and does.

Marathi + English: User Persona user बद्दल माहिती देतो, तर Empathy Map user काय think, feel, say आणि do करतो हे दाखवतो.

Q30. Give an example of a User Persona.

English: Rahul is a 22-year-old student who uses an online shopping app. His goal is to buy products easily, and his frustration is slow delivery.

Marathi + English: Rahul हा 22 वर्षांचा student आहे. तो online shopping app वापरतो. त्याला easily products buy करायचे आहेत, पण slow delivery ही त्याची problem आहे.
